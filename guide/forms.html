Basic Form Components

Form components handle user input data collection. To ensure reliability in production, they must combine predictable styling states with robust ARIA labeling and structural association.

1. Button

Problem Statement

Buttons trigger actions. Developers often use generic divs, anchor links with dummy hash URLs, or unstyled button elements, which strips default keyboard navigation (Enter/Space keys) and hides interaction states from screen readers.

Design & Accessibility Considerations

  • Focus Indicator: Must render a high-visibility ring on keyboard focus (using :focus-visible).
  • Disabled States: Set the native disabled attribute, which automatically tells screen readers the button is inactive and prevents action triggers.
  • Keyboard Actions: Native button element responds to the Enter and Space keys automatically.

TypeScript Interface

Button.types.ts
import { ButtonHTMLAttributes, ReactNode } from 'react';

export interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'primary' | 'secondary' | 'danger' | 'ghost';
  size?: 'sm' | 'md' | 'lg';
  isLoading?: boolean;
  leftIcon?: ReactNode;
  rightIcon?: ReactNode;
}

React Implementation

Button.tsx
import React from 'react';
import { ButtonProps } from './Button.types';
import './Button.styles.css';

export const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(({
  variant = 'primary',
  size = 'md',
  isLoading = false,
  disabled,
  children,
  leftIcon,
  rightIcon,
  className = '',
  ...props
}, ref) => {
  return (
    <button
      ref={ref}
      className={`btn btn-${variant} btn-${size} ${isLoading ? 'btn-loading' : ''} ${className}`}
      disabled={disabled || isLoading}
      aria-busy={isLoading}
      {...props}
    >
      {isLoading && <span className="btn-spinner" aria-hidden="true" />}
      {!isLoading && leftIcon && <span className="btn-icon btn-icon-left">{leftIcon}</span>}
      <span className="btn-text">{children}</span>
      {!isLoading && rightIcon && <span className="btn-icon btn-icon-right">{rightIcon}</span>}
    </button>
  );
});

Button.displayName = 'Button';

2. Input & TextArea

Problem Statement

Text inputs must convey validation states (error, success) and link with helper labels so screen readers describe validation instructions when focus enters the fields.

Accessibility Requirements

  • Label Association: The input must link with its label using an identical ID and htmlFor attribute.
  • Error Mapping: When in an invalid state, the input must have aria-invalid="true" and aria-describedby="[error-message-id]".

React Implementation (Input)

Input.tsx
import React, { InputHTMLAttributes } from 'react';

export interface InputProps extends InputHTMLAttributes<HTMLInputElement> {
  isInvalid?: boolean;
  errorId?: string;
}

export const Input = React.forwardRef<HTMLInputElement, InputProps>(({
  isInvalid = false,
  errorId,
  className = '',
  ...props
}, ref) => {
  return (
    <input
      ref={ref}
      className={`form-input ${isInvalid ? 'input-invalid' : ''} ${className}`}
      aria-invalid={isInvalid}
      aria-describedby={isInvalid ? errorId : undefined}
      {...props}
    >
  );
});

Input.displayName = 'Input';

3. Select

Problem Statement

Custom-styled selects often break native scroll overlays, keyboard search indexing (typing "U" to jump to United States), and mobile spinner wheels.

Design Recommendation

We recommend using a styled native select wrapper for basic forms. For complex searchable combobox dropdowns, utilize a headless system (like Radix or Aria) to preserve keyboard focus trapping.

Select.tsx
import React, { SelectHTMLAttributes } from 'react';

export interface SelectProps extends SelectHTMLAttributes<HTMLSelectElement> {
  isInvalid?: boolean;
}

export const Select = React.forwardRef<HTMLSelectElement, SelectProps>(({
  isInvalid,
  children,
  ...props
}, ref) => {
  return (
    <select ref={ref} aria-invalid={isInvalid} className="form-select" {...props}>
      {children}
    </select>
  );
});

4. Checkbox, Radio, & Switch

These components act as binary state controllers. They must utilize hidden native inputs wrapper divs to retain tab focus and action bindings, but style the overlay via CSS variables to render identical toggles across browsers.

TypeScript Switch Interface

Switch.types.ts
import { InputHTMLAttributes } from 'react';

export interface SwitchProps extends Omit<InputHTMLAttributes<HTMLInputElement>, 'type'> {
  label: string;
}

React Switch Implementation

Switch.tsx
import React from 'react';
import { SwitchProps } from './Switch.types';
import './Switch.styles.css';

export const Switch = React.forwardRef<HTMLInputElement, SwitchProps>(({
  label,
  id,
  checked,
  onChange,
  disabled,
  ...props
}, ref) => {
  return (
    <label className="switch-container" htmlFor={id}>
      <input
        ref={ref}
        type="checkbox"
        id={id}
        checked={checked}
        onChange={onChange}
        disabled={disabled}
        role="switch"
        aria-checked={checked}
        className="switch-input"
        {...props}
      />
      <span className="switch-slider" />
      <span className="switch-label-text">{label}</span>
    </label>
  );
});

5. Label, FormField, & FormGroup

These layout elements wrap inputs to bundle title labels, description hints, validation alerts, and input grids together.

  • Label: Simply renders text linked with input fields.
  • FormField: Maps labels and error messages to input states dynamically.
  • FormGroup: Manages layout grids (e.g. half-width inputs side-by-side) and distributes ids.

React FormField Example

FormField Usage
<FormField
  label="Email Address"
  isRequired
  error={formErrors.email}
  hint="We will never share your email."
>
  {(errorId) => (
    <Input
      type="email"
      id="email-field"
      isInvalid={!!formErrors.email}
      errorId={errorId}
      placeholder="you@domain.com"
    />
  )}
</FormField>
Label Requirement

Never replace visual labels with placeholders. Placeholders disappear once text is typed, making it impossible for users to check what data belongs in what field. Keep labels visible at all times.

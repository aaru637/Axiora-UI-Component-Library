Data Display Components

Data display components present complex datasets to the user. Designing them for enterprise scale involves balancing responsive scroll wrapping with high performance and accessibility.

1. Table & Data Grid

  • Table: A semantic HTML table (using <thead>, <tbody>, <tr>, and <th>). It is optimized for small to medium sets of static records.
  • Data Grid: A high-performance component featuring cell editing, row sorting, column resizing, and pagination. For tables containing over 100 rows, the Data Grid must implement **Virtualization** (rendering only visible rows in the viewport to maintain 60fps scrolling).

React Virtualization Principle Example

DataGrid.tsx
import React, { useRef, useState, useEffect } from 'react';

interface DataGridProps<T> {
  data: T[];
  rowHeight: number;
  containerHeight: number;
  renderRow: (item: T, index: number) => React.ReactNode;
}

export const DataGrid = <T,>({ data, rowHeight, containerHeight, renderRow }: DataGridProps<T>) => {
  const [scrollTop, setScrollTop] = useState(0);
  const containerRef = useRef<HTMLDivElement>(null);

  const totalHeight = data.length * rowHeight;
  const startIndex = Math.max(0, Math.floor(scrollTop / rowHeight) - 2);
  const endIndex = Math.min(data.length - 1, Math.floor((scrollTop + containerHeight) / rowHeight) + 2);
  
  const visibleRows = data.slice(startIndex, endIndex + 1);
  const offsetY = startIndex * rowHeight;

  return (
    <div
      ref={containerRef}
      onScroll={(e) => setScrollTop(e.currentTarget.scrollTop)}
      style={{ height: containerHeight, overflowY: 'auto', position: 'relative' }}
    >
      <div style={{ height: totalHeight, width: '100%' }}>
        <div style={{ transform: `translateY(${offsetY}px)`, position: 'absolute', left: 0, right: 0 }}>
          {visibleRows.map((item, idx) => renderRow(item, startIndex + idx))}
        </div>
      </div>
    </div>
  );
};

2. Accordion

Accordions group vertical items together. Clicking headings collapses or expands their descriptive details panels.

React Implementation & ARIA

Accordion.tsx
import React, { useState } from 'react';

interface AccordionItem {
  id: string;
  title: string;
  content: string;
}

export const Accordion = ({ items }: { items: AccordionItem[] }) => {
  const [expandedId, setExpandedId] = useState<string | null>(null);

  const toggle = (id: string) => {
    setExpandedId(expandedId === id ? null : id);
  };

  return (
    <div className="accordion-wrapper">
      {items.map((item) => {
        const isExpanded = expandedId === item.id;
        return (
          <div key={item.id} className="accordion-item">
            <h3>
              <button
                aria-expanded={isExpanded}
                aria-controls={`panel-${item.id}`}
                onClick={() => toggle(item.id)}
                className="accordion-trigger"
              >
                {item.title}
              </button>
            </h3>
            <div
              id={`panel-${item.id}`}
              role="region"
              hidden={!isExpanded}
              className="accordion-panel"
            >
              <p>{item.content}</p>
            </div>
          </div>
        );
      })}
    </div>
  );
};

3. Card, Timeline, Tree View & List

  • Card: A flexible containment block with rounded borders, drop shadows, and visual divisions.
  • Timeline: A vertical chronologically-ordered trail of milestones or updates.
  • Tree View: Hierarchical folders/files listings. Tree views must support keyboard navigation (Arrow keys to expand/collapse folders) and contain the role="tree" schema.
  • List: Standard wrapper for ordered, unordered, or semantic descriptive layout lists.
Tree View Keyboard Schema

An accessible Tree View requires that → expands closed folders, ← collapses open folders or moves focus up to the parent, and ↓ / ↑ moves focus between visible nodes.

Feedback Components

Feedback components inform the user of updates, processing states, validation warnings, or status updates. Selecting the correct notification style ensures applications communicate state clearly without interrupting task workflows.

1. Alert

Alerts display prominent inline notifications directly within the page grid, usually containing static context information.

React Implementation

Alert.tsx
import React, { ReactNode } from 'react';
import './Alert.styles.css';

interface AlertProps {
  status?: 'info' | 'success' | 'warning' | 'danger';
  title: string;
  children: ReactNode;
  onClose?: () => void;
}

export const Alert = ({ status = 'info', title, children, onClose }: AlertProps) => {
  return (
    <div className={`alert alert-${status}`} role="alert">
      <div className="alert-content">
        <span className="alert-title">{title}</span>
        <div className="alert-body">{children}</div>
      </div>
      {onClose && (
        <button className="alert-close-btn" onClick={onClose} aria-label="Close alert">
          &times;
        </button>
      )}
    </div>
  );
};

2. Toast & Notification

Toasts are temporal message overlays that slide onto the screen and dismiss automatically, while Notifications are larger, persistent dialogs that can contain rich actions.

Toast Accessibility Rule

Since toasts dismiss themselves automatically, they must not contain interactive elements (like buttons or link anchors) that require keyboard focus. Screen readers will struggle to focus on them before they fade. If actions are needed, use a persistent inline alert or notification drawer instead.

3. Badge

Badges are small status pills that highlight status metadata (e.g. "Completed", "Pending", "Failed") or counts (e.g. notification counts).

Badge.tsx
import React from 'react';

export interface BadgeProps {
  variant?: 'neutral' | 'success' | 'warning' | 'danger' | 'info';
  children: React.ReactNode;
}

export const Badge = ({ variant = 'neutral', children }: BadgeProps) => {
  return <span className={`badge badge-${variant}`}>{children}</span>;
};

4. Spinner & Skeleton

  • Spinner: A circular, spinning animation that indicates background data operations. Always wrap spinners in an element with role="status" and aria-live="polite" containing hidden text for screen readers.
  • Skeleton: Shimmering gray boxes that mimic layout cards during cold page mounts. Skeletons provide a smoother loading experience than spinner wheels.

React Skeleton Example

Skeleton.tsx
import React from 'react';
import './Skeleton.styles.css';

interface SkeletonProps {
  width?: string;
  height?: string;
  variant?: 'text' | 'rect' | 'circle';
}

export const Skeleton = ({ width, height, variant = 'rect' }: SkeletonProps) => {
  const styles: React.CSSProperties = {
    width: width,
    height: height,
    borderRadius: variant === 'circle' ? '50%' : variant === 'text' ? 'var(--radius-sm)' : 'var(--radius-md)'
  };
  return <div style={styles} className="skeleton-pulse" aria-hidden="true" />;
};

5. Progress Bar

The Progress Bar shows the completion status of a multi-step task or download operation.

Accessibility & Code

ProgressBar.tsx
import React from 'react';

interface ProgressBarProps {
  value: number; // 0 to 100
  label?: string;
}

export const ProgressBar = ({ value, label }: ProgressBarProps) => {
  const percentage = Math.min(Math.max(value, 0), 100);
  return (
    <div className="progress-wrapper">
      {label && <span className="progress-label">{label}</span>}
      <div
        className="progress-track"
        role="progressbar"
        aria-valuenow={percentage}
        aria-valuemin={0}
        aria-valuemax={100}
      >
        <div className="progress-fill" style={{ width: `${percentage}%` }} />
      </div>
    </div>
  );
};

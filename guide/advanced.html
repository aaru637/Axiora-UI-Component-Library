Advanced Enterprise Components

Advanced components involve complex user interfaces, asynchronous state interactions, and data rendering engine wrappers. At this layer, components should integrate established headless libraries to ensure robustness.

1. Date Picker & Date Range Picker

Calendars are notoriously difficult to design from scratch. They require dynamic leap-year math, weekend block rules, and intensive keyboard focus cycling.

  • Keyboard Spec: Arrow keys must navigate days (jumping rows on week boundaries), and Enter selects dates.
  • Recommendation: Use `@tanstack/react-virtual` or `react-day-picker` combined with native overlay popovers to handle positioning.

2. Multi Select, Auto Complete, & Command Palette

These components are all variations of the **Combobox pattern**:

  • Multi Select: Search input that appends selected records as dismissible "chips".
  • Auto Complete: Asynchronous typeahead text input listing filters in real-time.
  • Command Palette: Global overlay dashboard (like macOS Spotlight) triggered using Ctrl/Cmd + K.
Combobox Accessibility (WAI-ARIA)

Comboboxes must apply aria-autocomplete="list", aria-expanded="true/false", and map active search options using aria-activedescendant="[active-option-id]". This lets screen readers describe highlighting adjustments as keyboard arrows are pressed, without moving raw DOM focus out of the input text field.

3. Kanban Board & Workflow Builder

These canvas components handle complex card arrangement and workflow nodes layouts.

  • Kanban Boards: Drag cards between columns. We recommend using @dnd-kit/core to support keyboard-triggered movement (using Space to lift, arrow keys to move, and Space to drop).
  • Workflow Builder: Graphic canvas with connector wires (e.g. node charts). We recommend using React Flow or XState layouts to map state flows rather than re-creating canvas elements from scratch.

4. Rich Text Editor & File Upload

  • Rich Text Editor: Replaces basic textareas with WYSIWYG text formatting (bold, links, headers). Implement this using headless frameworks like TipTap or Lexical.
  • File Upload: Drag-and-drop dropzones with progress indicators. Ensure the container has an active onDragOver handler and a fallback native <input type="file"> element that is visually hidden but reachable via keyboard focus.

5. Data Visualization Wrapper

Abstracts complex chart libraries (like Recharts or Chart.js) into responsive containers aligned with the central design tokens color palette.

React Chart Wrapper Implementation

ChartWrapper.tsx
import React from 'react';
import { ResponsiveContainer, LineChart, Line, XAxis, YAxis, Tooltip, CartesianGrid } from 'recharts';
import './ChartWrapper.styles.css';

interface ChartData {
  name: string;
  value: number;
}

interface ChartWrapperProps {
  data: ChartData[];
  title: string;
  description: string;
}

export const ChartWrapper = ({ data, title, description }: ChartWrapperProps) => {
  return (
    <div className="chart-container" role="img" aria-label={`${title}: ${description}`}>
      <div className="chart-header">
        <h3 className="chart-title">{title}</h3>
        <p className="chart-description">{description}</p>
      </div>
      <div className="chart-body" style={{ width: '100%', height: 300 }}>
        <ResponsiveContainer>
          <LineChart data={data}>
            <CartesianGrid strokeDasharray="3 3" stroke="var(--border-color)" />
            <XAxis dataKey="name" stroke="var(--text-muted)" fontSize={12} />
            <YAxis stroke="var(--text-muted)" fontSize={12} />
            <Tooltip
              contentStyle={{
                backgroundColor: 'var(--bg-secondary)',
                borderColor: 'var(--border-color)',
                color: 'var(--text-primary)'
              }}
            />
            <Line type="monotone" dataKey="value" stroke="var(--primary-color)" strokeWidth={2} activeDot={{ r: 8 }} />
          </LineChart>
        </ResponsiveContainer>
      </div>
      
      {/* Accessible visual fallback table */}
      <details className="chart-table-details">
        <summary>View Data Table Alternative</summary>
        <table className="chart-fallback-table">
          <thead>
            <tr><th>Label</th><th>Value</th></tr>
          </thead>
          <tbody>
            {data.map((row, idx) => (
              <tr key={idx}><td>{row.name}</td><td>{row.value}</td></tr>
            ))}
          </tbody>
        </table>
      </details>
    </div>
  );
};

Foundation Components

Foundation components form the structural layout layer of the application. They are designed to abstract raw CSS layout properties (like flexbox, grid, padding, and semantic element types) into reusable, highly optimized React components.

1. Box

The Box is the most primitive layout component. By utilizing a polymorphic as prop, it can render any HTML element (e.g., div, section, span, header) while exposing spacing, borders, and theme tokens as props.

TypeScript Interface & Props

Box.types.ts
import { ReactNode, ElementType, ComponentPropsWithoutRef } from 'react';

export interface BoxProps<T extends ElementType = 'div'> {
  as?: T;
  children?: ReactNode;
  padding?: string | number;
  margin?: string | number;
  bg?: string;
  borderColor?: string;
  borderRadius?: string;
}

export type PolymorphicBoxProps<T extends ElementType> = BoxProps<T> & 
  Omit<ComponentPropsWithoutRef<T>, keyof BoxProps<T>>;

React Implementation

Box.tsx
import React from 'react';
import { PolymorphicBoxProps } from './Box.types';

export const Box = <T extends React.ElementType = 'div'>({
  as,
  children,
  padding,
  margin,
  bg,
  borderColor,
  borderRadius,
  style,
  ...props
}: PolymorphicBoxProps<T>) => {
  const Component = as || 'div';
  const customStyles: React.CSSProperties = {
    padding: padding,
    margin: margin,
    backgroundColor: bg ? `var(--color-${bg}, ${bg})` : undefined,
    borderColor: borderColor ? `var(--border-${borderColor}, ${borderColor})` : undefined,
    borderRadius: borderRadius ? `var(--radius-${borderRadius}, ${borderRadius})` : undefined,
    ...style
  };

  return (
    <Component style={customStyles} {...props}>
      {children}
    </Component>
  );
};
Box Anti-Pattern

Avoid using Box for basic layouts where semantic structure is required. Using nested <Box> elements with no as properties generates flat div hierarchies, which strips the layout of headings, lists, and regions, harming search engine indexes and accessibility.

2. Container

The Container centers content horizontally and applies responsive padding and maximum widths based on design breakpoints.

API Design & Usage

Container Example
// Width auto-constrains to desktop width tokens (e.g. max-width: 1280px)
<Container size="lg" centerContent>
  <Box bg="slate-100" padding="20px">Centered Content Grid</Box>
</Container>

3. Flex & Grid

These components abstract CSS Flexbox and CSS Grid properties to keep layout rules out of styling files.

  • Flex Props: direction (row/column), align (align-items), justify (justify-content), wrap (flex-wrap), gap.
  • Grid Props: columns (grid-template-columns), rows, gap, columnGap, rowGap.

React Flex Example

Flex Usage
<Flex direction="row" align="center" justify="space-between" gap="var(--spacing-4)">
  <Box>Brand Logo</Box>
  <Flex direction="row" gap="var(--spacing-2)">
    <Box as="a" href="/docs">Docs</Box>
    <Box as="a" href="/blog">Blog</Box>
  </Flex>
</Flex>

4. Stack & Spacer

Stack manages vertical or horizontal layout flow between immediate children, applying standard margins using CSS gap or adjacent selectors.

Spacer is a flexible element that expands to fill remaining empty space in parent Flex containers (using flex-grow: 1).

Stack Usage

Stack Implementation
<Stack direction="vertical" spacing="spacing-4">
  <Typography variant="h2">Card Title</Typography>
  <Typography variant="body">This is card description body text.</Typography>
  <Spacer />
  <Button>Read More</Button>
</Stack>

5. Typography

Typography renders semantic text elements (like h1, p, code) while mapping styles to the central font design tokens.

Variant Prop Semantic HTML Tag CSS Rules Mapping
h1 <h1> font-size: var(--font-size-4xl); font-weight: 700;
body <p> font-size: var(--font-size-base); font-weight: 400;
caption <span> font-size: var(--font-size-xs); color: var(--text-muted);

6. Icon & Divider

  • Icon: An inline SVG component wrapper. It inherits current text colors (fill="currentColor") and provides standardized sizes (e.g. small = 16px, medium = 24px).
  • Divider: A physical horizontal or vertical line (decorational by default, or semantic).
Divider Accessibility (ARIA)

When using Divider, always apply the correct attributes. A standard visual horizontal line should have role="separator" and aria-orientation="horizontal". If used as a decorative element with no semantic value, apply role="presentation" so screen readers ignore it.

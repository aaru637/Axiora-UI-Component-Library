Navigation Components

Navigation components guide users through application states, page structures, or wizard workflows. High-quality navigation requires clear styling and keyboard layout alignment.

1. Navbar & Sidebar

  • Navbar: The horizontal navigation header at the top of application layout. It must use the semantic <nav> element to define a landmark region.
  • Sidebar: Vertical navigation drawer typically used for complex dashboards. Sidebars must support collapsibility to optimize screen space on smaller monitors.

2. Breadcrumb

Breadcrumbs display the visual trail of the user's current location in the application hierarchy.

React Implementation & ARIA

Breadcrumb.tsx
import React from 'react';

interface BreadcrumbItem {
  label: string;
  href?: string;
}

interface BreadcrumbProps {
  items: BreadcrumbItem[];
}

export const Breadcrumb = ({ items }: BreadcrumbProps) => {
  return (
    <nav aria-label="Breadcrumb" className="breadcrumb-nav">
      <ol className="breadcrumb-list">
        {items.map((item, index) => {
          const isLast = index === items.length - 1;
          return (
            <li key={index} className="breadcrumb-item">
              {isLast || !item.href ? (
                <span aria-current="page" className="breadcrumb-active">{item.label}</span>
              ) : (
                <a href={item.href} className="breadcrumb-link">{item.label}</a>
              )}
              {!isLast && <span className="breadcrumb-separator" aria-hidden="true">/</span>}
            </li>
          );
        })}
      </ol>
    </nav>
  );
};

3. Tabs

Tabs organize related content into separate panes, displaying one pane at a time.

WAI-ARIA Keyboard Design Pattern

  • tablist: The container wrapping the tabs, marked with role="tablist".
  • tab: Individual tab control buttons, marked with role="tab" and aria-selected="true/false".
  • tabpanel: The panel content block, marked with role="tabpanel".
  • Keyboard Actions: Users should be able to navigate tab button lists using → and ← keys.
Tabs.tsx
import React, { useState } from 'react';

interface Tab {
  id: string;
  label: string;
  content: React.ReactNode;
}

export const Tabs = ({ tabs }: { tabs: Tab[] }) => {
  const [activeTab, setActiveTab] = useState(tabs[0]?.id);

  return (
    <div className="tabs-container">
      <div role="tablist" aria-label="Product Options" className="tabs-list">
        {tabs.map((tab) => (
          <button
            key={tab.id}
            role="tab"
            aria-selected={activeTab === tab.id}
            aria-controls={`panel-${tab.id}`}
            id={`tab-${tab.id}`}
            onClick={() => setActiveTab(tab.id)}
            className={`tab-btn ${activeTab === tab.id ? 'active' : ''}`}
          >
            {tab.label}
          </button>
        ))}
      </div>
      {tabs.map((tab) => (
        <div
          key={tab.id}
          id={`panel-${tab.id}`}
          role="tabpanel"
          aria-labelledby={`tab-${tab.id}`}
          hidden={activeTab !== tab.id}
          className="tab-panel"
        >
          {tab.content}
        </div>
      ))}
    </div>
  );
};

4. Pagination & Stepper

  • Pagination: Splitting collections into numbered pages. Make sure to label navigation wrappers with aria-label="Pagination" and mark active page indicators with aria-current="page".
  • Stepper: Step indicators for process flows (e.g. checkout forms). Steppers visually guide users and should clearly communicate completed versus incomplete stages.
Pagination Navigation Check

When paging operations refresh dynamic table cells asynchronously (via fetch), the container wrapping the updated data must have aria-live="polite" or role="status" so screen readers announce the reload state without losing user focus.

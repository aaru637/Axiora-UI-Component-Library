Storybook Integration Guide

Storybook provides an isolated playground to write, test, and document UI components in sandbox mode. This page details how to structure stories and generate interactive documentation.

Story Creation (CSF v3)

We use the industry-standard **Component Story Format (CSF v3)** to structure component files. Under CSF v3, stories are defined as objects containing state and meta configurations rather than template helper functions.

Example CSF v3 Story file

Button.stories.tsx
import type { Meta, StoryObj } from '@storybook/react';
import { Button } from './Button';

// 1. Meta configuration
const meta: Meta<typeof Button> = {
  title: 'Forms/Button',
  component: Button,
  tags: ['autodocs'], // Automates docs view generation
  argTypes: {
    variant: {
      control: 'select',
      options: ['primary', 'secondary', 'danger', 'ghost']
    },
    size: {
      control: 'radio',
      options: ['sm', 'md', 'lg']
    },
    isLoading: { control: 'boolean' },
    disabled: { control: 'boolean' }
  }
};

export default meta;
type Story = StoryObj<typeof Button>;

// 2. Stories objects definitions
export const Primary: Story = {
  args: {
    variant: 'primary',
    children: 'Primary Action'
  }
};

export const Secondary: Story = {
  args: {
    variant: 'secondary',
    children: 'Secondary Action'
  }
};

export const LoadingState: Story = {
  args: {
    variant: 'primary',
    isLoading: true,
    children: 'Saving Record'
  }
};

Documentation Autogeneration

By including the 'autodocs' tag in your story meta definitions, Storybook automatically compiles your TypeScript interfaces and JSDoc comments to generate an interactive API props reference table. Document your props cleanly using JSDoc tags:

Button.types.ts JSDoc markup
export interface ButtonProps {
  /**
   * The visual appearance variant class
   * @default 'primary'
   */
  variant?: 'primary' | 'secondary' | 'danger' | 'ghost';
  
  /**
   * Sets the button element active state to processing spinner
   */
  isLoading?: boolean;
}

Component Playgrounds & Controls

Using the argTypes controls panel, developers and designers can adjust color themes, toggles, text fields, and state selectors inside their web browser to preview component options in real-time, eliminating the need to write dummy test code.

Visual Regression Testing

By connecting Storybook to **Chromatic** (a cloud platform maintained by the creators of Storybook), every story is automatically rendered in virtual chrome/firefox viewports during Git commit pipelines. Chromatic takes screenshots of each view and flags visual modifications to keep designs consistent.

Storybook Theme sync

Configure the storybook-addon-themes plugin to match Storybook's playground background with your component's light/dark mode custom properties. This ensures components render correctly under both themes in the documentation viewer.
